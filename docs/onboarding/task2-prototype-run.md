# 任务二 · 把灰盒原型跑起来（非程序员专属指南）

> 目标读者：完全不懂编程的制作人。本文全程鼠标点击，不写任何代码。
> 前置条件：已完成「任务一」，电脑上已装好 **Unity 2022.3.62f3c1**，并建了一个 **3D (URP)** 工程。

---

## 一、最终目标（你要达成什么）

在**你自己的 Unity 工程**里，打开一个灰盒（灰色方块搭的）修仙试验场景，能看到：
- 一个斜 45° 俯视的固定视角，画面带**水墨/宣纸质感**（这就是我们要验证的"墨韵"效果）；
- 一个黄色玩家方块、一个绿色地面敌人、一个青色**浮空**敌人、一个红色 Boss 大方块；
- 屏幕左上角有 **FPS（帧率）/ Draw Calls / 三角形数** 的实时数字。

你真正要做的，是**亲自判断两件事**（这部分只有你能做，是实打实的贡献）：
- **H1（可读性）**：在这个斜角视角下，你能不能一眼分清"地面敌人"和"浮空敌人"？画面清不清楚？
- **H2（流畅度）**：左上角 FPS 是不是稳定在 60 左右？有没有卡顿？

判断完，把感受（截图或文字）发给我，我们就知道这个技术方向能不能往下走。

## 二、按顺序的操作步骤

### 步骤 0：找到你自己的 Unity 工程文件夹
1. 打开 **Unity Hub**（就是任务一里装的游戏引擎启动器）。
2. 在「Projects（项目）」页面，找到你之前建的那个 3D(URP) 工程卡片。
3. 把鼠标移到卡片上，点卡片右侧的 **「⋯」（三个点）→ Show in Explorer（在资源管理器中显示）**。
   → 会弹出一个文件夹窗口，这就是**你的工程文件夹**。
4. 双击进去，确认里面有一个叫 **`Assets`** 的文件夹（这是游戏资源的"仓库"）。

> 💡 如果你忘了工程叫什么，就在 Unity Hub 里看卡片名字；如果根本没有卡片，说明任务一没建成功，先回去重做任务一。

### 步骤 1：把我们的程序文件复制进你的工程
我们有两个文件夹要搬过去：**`Scripts`**（脚本）和 **`Shaders`**（着色器）。

1. 打开我们给你的文件所在位置：`D:\WBzone\Game\prototype\Assets\`
   （里面能看到 `Scripts` 和 `Shaders` 两个文件夹）。
2. 选中 `Scripts` 和 `Shaders` 这两个文件夹（按住 Ctrl 点两个）。
3. 右键 → **复制**（或按 Ctrl+C）。
4. 回到步骤 0 打开的**你的工程文件夹**里的 `Assets` 文件夹。
5. 在空白处右键 → **粘贴**（或按 Ctrl+V）。
6. Unity 会自动弹出「Importing（导入中）」进度条，等它走完。

> ⚠️ **千万不要**把你整个 `Assets` 文件夹替换掉，也不要动 `Assets` 以外的文件。只**复制进去** `Scripts` 和 `Shaders` 两个文件夹即可，Unity 会把它们和原有内容合并。

### 步骤 2：等 Unity 编译，看有没有红字报错
1. 切回 Unity 主界面。底部状态栏会显示 **「Compiling…（编译中）」**，等它消失。
2. 打开 **Console 窗口（控制台）**：顶部菜单 `Window（窗口）→ General（常规）→ Console`。
3. 看 Console 里：
   - **全是白色/黄色字** → 没问题，继续。
   - **有红色字（Error）** → 别慌，把红字内容截图发我，我来兜底。

### 步骤 3：生成"墨韵"材质（点一下菜单就行）
1. 看 Unity 顶部菜单栏，找到我们新增的 **`Greybox`** 菜单（在 Help 附近）。
2. 点 **`Greybox → Create Ink Material`**。
3. Console 会显示一行绿字「已生成墨韵材质」。
   → 这时你的 `Assets` 里多了一个 `Materials` 文件夹，里面有 `InkMaterial.mat`。

> 如果菜单栏**根本没有 Greybox**：说明步骤 2 还有编译错误没过，看 Console 红字发我。

### 步骤 4：让墨韵效果生效（在渲染设置里挂一下）
1. 在 **Project 窗口（下方资源列表）** 右上角的搜索框，输入 **`Renderer`**。
2. 找到名字类似 **`UniversalRenderPipelineAsset_Renderer`**（或 `URP_Renderer`）的文件，双击选中它。
3. 看右侧 **Inspector 面板（属性面板）**，往下拉，找到 **`Renderer Features`（渲染功能）** 这一栏。
4. 点它下面的 **`Add Renderer Feature（添加渲染功能）`** 按钮 → 在弹出的列表里选 **`Ink Render Feature`**。
5. 这时列表里多了一项「Ink Render Feature」，展开它，能看到一个 **`Ink Material`** 的空槽（小方块）。
6. 把步骤 3 生成的 **`InkMaterial.mat`**（在 `Assets/Materials` 里）**拖进这个空槽**；或点空槽右边的小圆圈，在弹窗里选 `InkMaterial`。

> 如果搜不到 `Renderer` 文件：在 Project 窗口里手动翻 `Assets → Settings` 文件夹，渲染器资产通常在那里。实在找不到就发我截图。

### 步骤 5：一键搭建灰盒场景
1. 顶部菜单 **`Greybox → Rebuild Scene`**。
2. 等 1～2 秒，Scene 视图（中间的大画面）里会"长"出灰盒：地面、墙、三个敌人、玩家、相机。
   （如果此刻你点过运行又停了，重复点一次这个菜单即可，它会自动清掉旧的再建。）

### 步骤 6：点运行，开始测试
1. 点 Unity 上方中间的 **▶（Play 运行）** 按钮。
2. Game 视图（运行后中间画面）里，你应该看到：
   - 斜 45° 俯视的水墨风灰盒场景；
   - 左上角有 FPS / Draw Calls / Triangles 数字；
   - 黄色玩家方块，WASD 能移动，空格翻滚，鼠标左键攻击（敌人会闪红）；
   - 绿色敌人在地面、青色敌人**浮在空中**、红色大方块是 Boss。
3. 走动几圈，观察 H1 和 H2（见第三节）。

## 三、你要判断的两件事（H1 / H2）

**H1 · 可读性（斜 45° 下能不能看清敌人在哪）**
- 你能一眼分出"地面绿色敌人"和"浮空青色敌人"吗？
- 墙、门洞、房间之间的连通，看着清楚吗？
- 如果觉得"糊成一团、分不清谁在天上谁在地上" → 这就是失败信号，记下来告诉我。

**H2 · 流畅度（帧率稳不稳）**
- 盯左上角 **FPS**：目标 **60 左右**（50~60 都可接受）。
- 有没有明显卡顿、掉帧、画面撕裂？
- 如果 FPS 掉到 30 以下或一直在跳 → 记下来（连同 Draw Calls / Triangles 数字）告诉我。

## 四、常见错误与解决办法

| 现象 | 可能原因 | 解决办法 |
|---|---|---|
| 菜单栏没有 `Greybox` | 步骤 2 编译有红字报错 | 看 Console 红字，截图发我 |
| Console 一堆红色 Error | 文件没复制全 / 复制错了位置 | 确认 `Scripts` 和 `Shaders` 都进了 `Assets`，且 `Scripts` 里包含 `Editor` 子文件夹 |
| 点了 `Rebuild Scene` 但画面空的 | 没点运行，或场景没刷新 | 先点 ▶ 运行；若仍空，再点一次 `Greybox → Rebuild Scene` |
| 画面是黑的 / 没有水墨感 | 步骤 4 没挂 Ink Render Feature，或没拖材质 | 回步骤 4 重做，确认 `InkMaterial` 已拖进槽里 |
| FPS 显示 0 | 数字每 0.5 秒刷新一次，刚进去要等一下 | 等 1 秒再看 |
| 玩家掉到地下 / 穿墙 | 灰盒地面高度问题，不影响验证 | 忽略，告诉我也行 |
| 找不到 `Renderer` 资产 | 工程模板差异 | 翻 `Assets/Settings` 文件夹，或发我截图 |

> 任何一步卡住，**把屏幕上的红字或截图发我**，不要自己改代码——那是我的活。
