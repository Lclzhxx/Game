# 任务一：把游戏工具（Unity）装好并跑起来

> 适用对象：没有任何编程基础的项目成员  
> 目标：在你的电脑上安装「Unity 2022.3 LTS」并新建一个空的「3D(URP) 工程」，确认能正常打开、能点「运行」看到画面。  
> 重要心态：**写代码不是你的事**。你只需要做「装软件 → 打开 → 试玩 → 把感受告诉我」。这一步结束之后，真正的游戏画面由我来接手做。

---

## 一、这一步最终要达到什么？

你会在自己电脑上装好一个叫 **Unity** 的「游戏制作软件」（可以理解成：做游戏用的专业工具，就像剪视频用剪映、写文档用 Word）。装好后：

- 你能用 Unity Hub（Unity 的启动器）打开一个空白「工程」（工程 = 一个游戏项目的文件夹）。
- 你点一下「运行」按钮，能看到 Unity 的工作画面亮起来（哪怕只是空的）。
- 之后我会把做好的游戏程序文件发给你，你放进去、点运行，就能在电脑上看到最初的修仙试验画面（灰色方块搭的小场景），用来帮我们判断「斜着角度看不看得清敌人」「画面流不流畅」。

**完成标准（三条全满足 = 任务一做完）**：

1. 电脑装好了 Unity 2022.3 LTS。
2. 你能用 Unity Hub 打开自己新建的 3D(URP) 工程。
3. 点「运行」能看到游戏画面，且屏幕上**没有一大片红色报错文字**。

---

## 二、开始前：检查你的电脑

| 检查项  | 要求                    | 怎么看                      |
| ---- | --------------------- | ------------------------ |
| 系统   | Windows 10 或 11（64 位） | 右键「此电脑」→「属性」里看           |
| 硬盘空间 | 至少 30 GB 空闲           | 打开「此电脑」，看 C 盘或你装软件的盘剩余空间 |
| 网络   | 能正常上网                 | 能打开网页即可                  |
| 邮箱   | 一个能收邮件的邮箱             | 用来注册 Unity 账号（免费）        |

> 如果硬盘空间不够，建议先把不用的文件清理一下，或装到空间大的盘。

---

## 三、按顺序排列的具体步骤

### 步骤 1：下载并安装 Unity Hub（Unity 的「管家」）

**动作说明**：

1. 打开浏览器，在地址栏输入官网：`unity.com`，按回车。
2. 在页面里找「下载 / Download」，下载 **Unity Hub**（注意是 Hub，不是别的）。
3. 下载得到的是一个安装包（文件名类似 `UnityHubSetup.exe`）。
4. 双击它 → 一路点「下一步 / 我同意 / 安装」→ 最后点「完成」。
5. 桌面上会出现 Unity Hub 的图标。

**常见问题**：

- 下载很慢 / 卡住 → 换个网络（比如手机热点）再试，或关掉重新下载。
- 安装到一半报错 → 关掉，右键安装包选「以管理员身份运行」再装一次。

---

### 步骤 2：注册并登录 Unity 账号（免费）

**动作说明**：

1. 双击打开 Unity Hub。
2. 第一次打开会让你「登录 / 注册」。点「创建账号 / Create account」。
3. 用你的邮箱注册（全程免费，不用付钱）。
4. 去邮箱收一封验证邮件，点里面的链接激活账号。
5. 回到 Unity Hub 用刚注册的账号登录。

**常见问题**：

- 收不到验证邮件 → 先看「垃圾邮件 / 广告邮件」文件夹；还是没有就换个邮箱重试。
- 提示账号已存在 → 直接用那个邮箱登录，忘记密码就点「忘记密码」重置。

---

### 步骤 3：安装指定版本的 Unity（⚠️ 版本必须锁死）

**为什么这一步很关键**：我们的游戏用了一套特殊的「水墨画面效果」，不同 Unity 版本的接口不一样。装错版本，后面一定会报错。所以这里**只装 2022.3 LTS**，别的都不要。

**动作说明**：

1. 在 Unity Hub 左侧点「安装 / Installs」。
2. 点右上角「安装编辑器 / Install Editor」。
3. 在版本列表里找到并选中 **Unity 2022.3 LTS**（一定认准 **LTS** 三个字母；不要选带 `a`/`b`/`c` 的测试版，也**不要选「Unity 6」**）。
   - 如果列表很长，用上方的搜索框搜 `2022.3` 最快。
4. 右边会让你勾选「模块」，至少确保勾上：
   - **Microsoft Visual Studio**（不用管它是什么，勾上就行，后面写代码的人用）
   - **Windows 构建支持 / Windows Build Support**（默认通常会勾）
5. 点「安装 / Install」，然后去喝杯水——根据网速可能要 20–40 分钟。

**常见问题**：

- 列表里找不到 2022.3 LTS → 用搜索框搜 `2022.3`；或确认你的 Unity Hub 是最新版（步骤 1 装的）。
- 安装失败 / 报错 → 关掉 Unity Hub，右键它的图标「以管理员身份运行」再装。
- 不小心装成了别的版本 → 没关系，在「安装」里把错的那个卸载掉，重新装 2022.3 LTS 即可。

---

### 步骤 4：新建一个「3D(URP) 工程」

**动作说明**：

1. 在 Unity Hub 上方点「项目 / Projects」。
2. 点「新建项目 / New Project」。
3. **模板一定要选「3D（URP）」**（URP 是我们游戏需要的画面管线；别选成普通「3D」，也别选「2D」）。
4. 工程名字随便起，比如 `XianXiaProto`。
5. 工程位置选一个你找得到的地方（建议：在桌面新建一个文件夹叫「我的游戏」，选它）。
6. 点「创建 / Create」。Unity 会自动打开这个工程（**第一次打开会比较慢，可能要等几分钟，耐心等**）。

**常见问题**：

- 模板列表里没看到「3D（URP）」→ 确认步骤 3 的 2022.3 LTS 已经装好并出现在「安装」列表里。
- 点创建后一直转圈打不开 → 多等几分钟；还不行就完全关闭 Unity Hub 再重开试试。
- 打开后界面是英文的 → 不影响，照着本指南里的按钮形状找；后续我可以教你换成中文界面。

---

### 步骤 5：确认工程能正常打开并运行

**动作说明**：

1. 工程打开后，你会看到几个大窗口拼在一起：
   - 中间一块是「场景」视图（你在编辑游戏的地方）
   - 中间上方有一排按钮，其中一个是三角形 **▶（运行）**，旁边是 ■（停止）
   - 左边是「层级 / Hierarchy」，右边是「检视 / Inspector」
2. 点一下那个三角形 **▶（运行）** 按钮。
3. 中间上方会出现一个「Game / 游戏」画面标签并亮起来（可能显示一片空地，或相机看到的默认画面）。
4. 再点一下 ■（停止）按钮，画面变暗，回到编辑状态。

**常见问题**：

- 点运行后一片红字报错 → **别慌**，这是常见小问题。记下最上面两三行红字，发给我，我来修。
- 点运行是黑屏但没红字 → 等几秒让它加载；还黑就关掉工程重开一次。
- 完全卡死不动 → 强制关掉 Unity Hub，重新打开工程。

---

## 四、怎么判断任务一真的做完了？

对照下面三条，全打勾就完成：

- [x] ✅ 电脑上装好了 **Unity 2022.3 LTS**（在 Unity Hub 的「安装」里能看到它）。
- [x] ✅ 你能用 Unity Hub 打开自己新建的 **3D(URP) 工程**。
- [x] ✅ 点「运行 ▶」能看到游戏画面（哪怕只是空的），且**没有红色错误文字**。

完成后，请把一件事告诉我：**你在 Unity Hub 的「安装」里看到的 2022.3 具体版本号**（比如 `2022.3.22f1`）。我下一步就会把做好的游戏程序文件交给你，你放进去、点运行，就能试玩了。

## 五、（预览）任务二会是啥？不用现在做

等你完成任务一，我会生成几个「游戏程序文件」（电脑上显示后缀是 `.cs` 的文件）。你接下来要做的也很简单：

1. 用电脑自带的「文件资源管理器」，把我给你的这些文件**复制**进你工程里的 `Assets` 文件夹（就是个普通复制粘贴，和拷照片一样）。
2. Unity 会自动识别它们。
3. 你点「运行 ▶」，就能在一个**灰色方块搭的修仙试验场景**里走动。
4. 你要帮我们判断两件事（这就是你的测试工作）：
   - **斜着的角度看不看得清敌人**（这叫 H1 测试）
   - **画面流不流畅、卡不卡**（这叫 H2 测试）
5. 把你的感受（比如「敌人和背景混在一起看不清」「有点卡」）告诉我，我来调整。

你看，从头到尾你都不用写一行代码。先把任务一做了就行。
